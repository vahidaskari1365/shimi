# شیمی‌یار — AI Formulation Assistant (MVP)

دستیار پژوهشی هوشمند برای فرمولاسیون شوینده، آرایشی و بهداشتی — با بازیابی ترکیبی (BM25 + برداری + RRF)، استناد صفحه‌به‌صفحه، گراف دانش و عیب‌یابی محتاطانه.

## اجرای سریع

```bash
bun install
cp .env.example .env
bun run db:push
bun run dev          # http://localhost:3000
```

دادهٔ نمایشی مصنوعی: تب «تنظیمات» → «بارگذاری دادهٔ نمایشی مصنوعی».

## هشدار

نمونهٔ اولیهٔ پژوهشی؛ جایگزین شیمی‌دان، آزمایش، بازبینی ایمنی و مقررات نیست. احراز هویت ندارد و فقط در محیط محلی/داخلی اجرا شود.
